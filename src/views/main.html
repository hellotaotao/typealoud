      How the dictionary is used

      Type a word and press Enter, or paste a list separated by commas. Changes save automatically.

      When you use a cloud engine, these words go to the model as a reference. They are more likely to come out right, but not every time.

      Automatic punctuation for Chinese

      When Whisper transcribes Chinese, TypeAloud sends the example below to the model to help it add punctuation. The example is fixed and contains none of your data; GPT models and other languages don't use it.
